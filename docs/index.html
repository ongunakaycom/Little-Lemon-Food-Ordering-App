🍋 Little Lemon

iOS Food Ordering App • Meta iOS Developer Certificate Capstone

About the App

A SwiftUI-based iOS application for a fictional Mediterranean restaurant, built as the capstone project for the Meta iOS Developer Professional Certificate on Coursera. Demonstrates modern iOS development practices including SwiftUI, CoreData persistence, MVVM architecture, and Combine framework.

🛠 Technologies

Swift 5.7+ SwiftUI MVVM CoreData Combine Xcode 14+ iOS 15+

✨ Key Features

1 Onboarding with persistent user profile
2 Menu with search & filtering
3 Detail Views with AsyncImage
4 User Profile with encryption
5 CoreData persistence

Built with ❤️ during the Meta iOS Developer Certificate program
